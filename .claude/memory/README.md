# memory — 项目知识库

这个目录是 Agent 团队的**共享长期记忆**：存放从代码和开发过程中沉淀的事实性知识。Claude Code 不会自动加载它们，靠 CLAUDE.md 与各 agent 提示词里的"接任务先读 memory"约定生效。

## 文件清单

| 文件 | 主题 |
|---|---|
| `business.md` | 产品功能全景、优先级、业务口径 |
| `architecture.md` | 技术选型与理由、目录结构、关键设计决策、LLM 接入方式 |

## 维护规则

1. **一文件一主题**：新知识先看能否并入既有文件，避免碎片化。
2. **事实而非教程**：写"是什么/为什么这么定"，不写教程式长文。
3. **更新时机**：架构或业务事实发生变化的功能完成后，由责任 agent 当场更新（development-flow 的流程出口要求）。
4. **与代码冲突时**：以代码为准，agent 负责反馈差异并修正本目录。
5. 随开发推进可新增主题文件（如 `prompts-notes.md` 沉淀 prompt 技巧），并在本清单登记。
